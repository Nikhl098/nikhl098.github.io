Caloyaa: cafe ordering test plan

The project

A test-planning and defect-analysis project based on the real Caloyaa cafe ordering flow. The public storefront lets customers browse food, build a basket and send an order request; the owner dashboard receives and manages orders. Documented in September 2026.

System under test

  • Customer storefront: menu, basket, checkout and optional WhatsApp fallback
  • Owner-only order dashboard: order intake, refresh, notifications and status changes
  • Order alerts: Telegram delivery and browser-side sound/pop-up

What’s inside

  • Test plan: objectives, scope, approach, risks, entry/exit criteria and deliverables
  • Test cases: customer and owner-flow checks, with expected results and evidence status
  • Defect log: three real issues, observed impact, fixes and verification limits

Scope note: this is a case study, not a claim that every listed test passed.
