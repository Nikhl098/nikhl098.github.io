What broke while building it

The first run had failures. SauceDemo’s current build did not respond to normal WebDriver clicks in headless Chrome, and the checkout form kept only the first field typed. The page objects therefore click and type through JavaScript. A later test with standard clicks, explicit waits and no JavaScript failed 2 of 7 in one run and 3 of 7 in another. This is a workaround, so these 7 tests do not prove that real mouse and keyboard input works. See the repo README and docs/ for the Maven output.

Built with AI assistance (Instinct). The tests were run against the live site and the results above come from that run.
